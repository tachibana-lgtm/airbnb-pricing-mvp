参照データの考え方

参照元: Holidays JP API / 参照確認先: 内閣府 国民の祝日

画面ではHolidays JP APIを自動取得。公的な最終確認先は内閣府の祝日資料。

天気・降水・気温 自動取得

参照元: Open-Meteo Forecast API

対象日が予報範囲内の場合のみ取得。価格係数への反映は控えめ。

宿泊需要・季節性 未連携

参照元: 観光庁 宿泊旅行統計調査、e-Stat、自治体観光統計

月別宿泊者数や稼働率で季節係数を補正する候補。APIキーや集計設計が必要。

イベント 手入力

参照元: 自治体・公式観光サイト・施設公式カレンダー

開催日、会場距離、来場者規模、競合在庫を合わせて扱う必要がある。

ホテル平均価格 手入力

参照元: OTA/API/手入力CSV

今は入力値を使用。将来は対象ホテル数、取得日、客室条件を記録する。

Airbnb競合価格 手入力

参照元: 手入力、PMS、外部データ会社、低頻度取得

今は入力値を使用。広さ、駅距離、レビュー、清掃費込み価格で補正が必要。

自社実績 最重要
